# CHRONO CIRCUIT v0.8 — Answer Modes

**Status:** Accepted release specification. Verify the live deployment separately.

## Change

Provide four protected instructional modes: **Teach**, **Guide**, **Independent**, and **Mastery**. An adult-only six-digit PIN protects mode selection and developer controls. The player-facing game must clearly communicate the active mode without exposing the PIN.

## Must retain

- Eight-stage, retro action-platform identity; time-arithmetic gates; touch-first play; keyboard support where claimed.
- Local-only progress and the existing power/boss progression.
